# 🚀 Smart Internship Matcher (SIM)

> **Explainable AI Eligibility & Skill-Gap Platform** built for SaarthiX Hackathon. SIM bridges the gap between student profiles and tech internships through transparent two-tier evaluation and dynamic 5-factor weighted scoring.

---

## 🌟 Key Features

1. **Two-Tier Decoupled Evaluation Architecture**: Separates mandatory eligibility checks (Graduation Year, Degree, Minimum CGPA cutoff) from weighted skill scoring to ensure transparent qualification gating.
2. **Dynamic 5-Factor Weighted Scoring Engine**: Computes real-time alignment across:
   - Technical Skills (35%)
   - Education Relevance (20%)
   - Project & Experience (20%)
   - Location & Work-Mode Preferences (15%)
   - Certifications & Extras (10%)
3. **Skill-Gap & Evidence Breakdown**: Instantly highlights exact matched skills, missing mandatory/preferred requirements, and generates actionable portfolio remediation paths.
4. **End-to-End Student Workflow**: Includes Live Profile & Resume Studio (.PDF/.TXT keyword parsing), multi-criteria internship discovery, status pipeline tracker, and Dark/Bright theme toggle.
